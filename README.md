# 👩‍💻 Bootcamp Santander Code Girls (DIO) - Cloud AWS & DevOps 2025

Repositório centralizado contendo todos os projetos, desafios práticos e materiais desenvolvidos durante o **Bootcamp Santander Code Girls**, em parceria com a **DIO (Digital Innovation One)**.

## 🎯 Objetivo do Bootcamp

Esta jornada de capacitação intensiva foi totalmente focada em **Cloud Computing** com a **Amazon Web Services (AWS)** e nas práticas modernas de **DevOps** e **Infraestrutura como Código (IaC)**.

O objetivo principal é construir uma base sólida para atuar como Cloud Engineer, com proficiência em automação, arquitetura Serverless e orquestração de serviços.

## 🌟 Destaques da Trilha de Aprendizagem

A trilha cobriu tópicos essenciais para arquiteturas escaláveis e consistentes na nuvem:

| Área de Foco | Serviços e Tecnologias Chave |
| :--- | :--- |
| **Infraestrutura como Código (IaC)** | **AWS CloudFormation** (Templates YAML/JSON), Terraform (Comparativo). |
| **Orquestração** | **AWS Step Functions** (Fluxos de trabalho visuais e assíncronos). |
| **Arquitetura Serverless** | **AWS Lambda**, Amazon S3, Amazon DynamoDB, e **LocalStack** (Desenvolvimento local). |
| **DevOps & Automação** | Padronização, consistência e implantação rápida de ambientes. |

## 📂 Visão Geral dos Desafios e Projetos

As pastas abaixo contêm a documentação detalhada (incluindo READMEs e códigos) de cada desafio ou projeto prático realizado.

| Pasta | Descrição | Foco Tecnológico |
| :--- | :--- | :--- |
| **02-HandsOn-StepFunctions** | Implementação de um fluxo de trabalho assíncrono para orquestração de tarefas na AWS. | Step Functions, Event-Driven |
| **03-IaC-CloudFormation** | Implementação da primeira Stack com CloudFormation (Templates YAML) para provisionamento de recursos AWS. | CloudFormation, IaC, EC2 |
| **04-Automacao-Governanca-CloudFormation** | Aprofundamento na IaC, focado em governança, padronização e no comparativo CloudFormation vs. Terraform. | CloudFormation, Governança
| **05-Serverless-Processamento-Arquivos** | Criação de uma arquitetura Serverless completa para processar uploads de arquivos (S3 Trigger -> Lambda -> DynamoDB). | Serverless, Lambda, DynamoDB, LocalStack |
